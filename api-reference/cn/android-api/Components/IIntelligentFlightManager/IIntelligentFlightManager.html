      class IIntelligentFlightManager

      包：dji.v5.manager.interfaces
      描述：

      此类是智能飞行管理类，支持飞行器的自动识别，聚焦（Spotlight），环绕（POI），智能跟随（Track），飞向目标点等高级智能功能。

      MSDK 5.14.0开始支持
