      setMegaphoneIndex

      Since MSDK 5.0.0
      包：dji.v5.manager.interfaces

      设置目标喊话器的位置。请根据已连接的喊话器位置进行设置。对于可以支持多个喊话器的机型，可以调用这个接口选择目标喊话器进行设置和操作。如果不调用此接口，MSDK会默认选择一个已连接的喊话器进行操作。

      startPushingFileToMegaphone

      startPushingFileToMegaphone

      Since MSDK 5.0.0
      包：dji.v5.manager.interfaces

      传输TTS数据或者音频文件到喊话器。当数据传输完成后，你可以调用startPlay 接口进行播放。

      注意
      流式传输模式的数据必须为 OPUS 编码格式的音频数据。如果是 MP3 文件，请用 PCMTools 转换为 OPUS 文件，从 MSDK 5.14.0 版本开始将不再支持通过 DJI 转化的 OPUS 文件。

      参数

      名称类型说明
      fileInfo@NonNull FileInfo 文件信息。
      callback@Nullable CommonCallbacks.CompletionCallbackWithProgress<Integer> 返回执行结果的回调。

      startRealTimeTransmission

      Since MSDK 5.0.0
      包：dji.v5.manager.interfaces

      开启流式传输模式。你可以调用sendRealTimeDataToMegaphone向喊话器发送需要播放的数据，调用appendEOFToRealTimeData添加EOF标志位，表示数据发送完毕。然后调用startPlay接口进行播放。

      注意
      流式传输模式的数据必须为OPUS编码格式的音频数据。

      参数

      名称类型说明
      callback@Nullable CommonCallbacks.CompletionCallback 返回执行结果的回调。
