      批量更新地图控件。

      按 id 匹配，对每个 widget 就地更新属性（不会产生视觉闪烁）。列表中任一 widget 的 id 不存在或试图修改不可变字段（id / source / layerId），整批更新失败，不会发起 IPC。

      以下字段不可通过本方法修改，否则回调 WIDGET_FIELD_IMMUTABLE 错误：id（widget 唯一标识，不可变）；source（来源包名，不可变）；layerId（所属图层，如需将 widget 移动到其他图层，请先 removeMapWidgetsByIds 再重新 addMapWidgets）。

      注意：受 Android Binder 传输限制，单次批量更新的数据总量不应超过 512KB。超限时回调 PAYLOAD_TOO_LARGE 错误。

      参数

      名称类型说明
      widgets@NonNull List<MapWidget> 地图控件列表。
      callbackCommonCallbacks.CompletionCallback 结果回调。

      批量添加地图控件。

      一次 IPC 调用完成多个控件的添加，适用于 GIS 数据批量同步场景。

      注意：受 Android Binder 传输限制，单次批量添加的数据总量不应超过 512KB。建议单次不超过 500 个简单 Marker 控件，或 200 个含坐标列表的折线/多边形控件。超限时回调 PAYLOAD_TOO_LARGE 错误。

      添加图层。

      图层是地图控件的逻辑分组容器，可按业务语义将 MapWidget 组织到不同图层中（如"火点层"、“人员层”），支持整层显隐、整层清空。一个图层可包含任意 DrawerType 的 MapWidget。

      参数

      名称类型说明
      layer@NonNull MapWidgetLayer 图层。
      callbackCommonCallbacks.CompletionCallback 结果回调。
