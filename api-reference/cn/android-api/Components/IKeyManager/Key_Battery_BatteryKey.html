      BatteryKey

      BatteryKey提供了一组方法来管理飞行器电池的信息和实时状态。通过设置componentIndex来获取对应电池的信息和实时状态。

      Package dji.sdk.keyvalue.keyAndroid · Java / Kotlin
      描述：

      BatteryKey提供了一组方法来管理飞行器电池的信息和实时状态。通过设置componentIndex来获取对应电池的信息和实时状态。 以M30系列飞行器为例：0表示Pilot中的电池1(左)、1表示Pilot中的电池2（右）。


      MSDK 5.0.0开始支持

      满电电量
      KeyFullChargeCapacity
      method

      KeyFullChargeCapacity

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      参数: Integer

      获取电池充满时的电池容量，单位：mAh。随着电池的持续使用，充满电时电池的容量会随着时间而减小。

      剩余电量
      KeyChargeRemaining
      method

      KeyChargeRemaining

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      参数: Integer

      获取电池剩余容量，单位：mAh。

      剩余电量百分比
      KeyChargeRemainingInPercent
      method

      KeyChargeRemainingInPercent

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      参数: Integer

      获取电池剩余电量百分比。如果你需要获取所有电池的总电量百分比，可以通过设置不同的componentIndex获取到所有的电池剩余电量和电池容量进行计算获取。

      高电压存储
      KeyBatteryHighVoltageStorageTime
      method

      KeyBatteryHighVoltageStorageTime

      Since MSDK 5.3.0
      包：dji.sdk.keyvalue.key

      参数: Long

      获取高电压存储时间。单位：秒。电池电量90%（含）以上状态存储时间。12个月内，电池高电压存储累计时间少于120天，其循环次数可达400次。可通过修改电池自放电天数调整高电压存储时间。

      温度

      KeyBatteryTemperature

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      参数: Double

      获取电池温度，单位：摄氏度。范围区间：[-128, 127]。

      电流

      KeyCurrent

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      参数: Integer

      获取电池的实时电流消耗，单位：mA。 负值表示电池正在放电，正值表示正在充电。

      放电次数

      KeyNumberOfDischarges

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      获取电池在其生命周期内经历的总放电次数。放电总数包括通过正常使用发生的放电和手动设置的放电。

      基本设置

      自放电
      KeyBatterySelfDischargeInDays
      method

      KeyBatterySelfDischargeInDays

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      参数: Integer

      设置和获取电池开始自放电天数，范围区间：[1, 10]。为了保证电池安全，当长时间放置电池的天数超过自放电天数时，电池会自动放电到安全放置电量。
