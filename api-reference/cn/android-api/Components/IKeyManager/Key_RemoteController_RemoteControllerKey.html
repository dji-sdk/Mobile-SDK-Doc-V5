      RemoteControllerKey

      RemoteControllerKey提供了一组方法来设置和获取遥控器数据。遥控器是一种具有摇杆、按钮、滚轮、GPS、电池、和视频输出端口的设备。移动设备可以连接到遥控器，遥控器会向移动设备发送任何从飞行器上返回的信息。

      Package dji.sdk.keyvalue.keyAndroid · Java / Kotlin
      描述：

      RemoteControllerKey提供了一组方法来设置和获取遥控器数据。遥控器是一种具有摇杆、按钮、滚轮、GPS、电池、和视频输出端口的设备。移动设备可以连接到遥控器，遥控器会向移动设备发送任何从飞行器上返回的信息。

      基本操作

      对频
      KeyRcFirmwareInfo
      method

      KeyRcFirmwareInfo

      Since MSDK 5.4.0
      包：dji.sdk.keyvalue.key

      获取遥控器当前的固件信息。

      注意
      此Key只支持DJI RC Plus遥控器和DJI RC N1遥控器，用于获取遥控器固件信息进行固件类型切换。

      KeySwitchRcFirmware
      method

      KeySwitchRcFirmware

      Since MSDK 5.4.0
      包：dji.sdk.keyvalue.key

      切换遥控器固件类型。以DJI RC Plus遥控器为例：DJI RC Plus遥控器可以用于M30系列机型，M300 RTK机型和M350 RTK机型。你可以调用这个接口切换不同机型的固件，然后调用KeyRequestPairing进行对频使用。

      KeyRequestPairing
      method

      KeyRequestPairing

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      启动遥控器对频操作，遥控器开始与飞行器对频。 当遥控器无法连接飞行器或者更换遥控器的时候可以通过对频操作连接飞行器。

      注意
      DJI RC Plus遥控器和DJI RC N1遥控器支持多款飞行器类型。请先调用KeyRcFirmwareInfo获取当前遥控器的固件类型。如果固件类型与需要对频的飞行器类型不一致，请先调用KeySwitchRcFirmware把遥控器固件切换成需要对频的固件类型后才能进行对频操作。

      KeyStopPairing
      method

      KeyStopPairing

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      停止遥控器对频操作。

      KeyPairingStatus
      method

      KeyPairingStatus

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      参数: PairingState


      获取遥控器对频状态。

      云台控制
      KeyControllingGimbal
      method

      KeyControllingGimbal

      Since MSDK 5.7.0
      包：dji.sdk.keyvalue.key

      参数: ComponentIndexType


      设置遥控器需要控制的云台和相机。飞行器上电后，遥控器默认控制主（左）云台和相机。可以通过此接口设置遥控器控制右云台和相机或者上云台和相机。


      注意


      支持机型：M300 RTK和M350 RTK。

      KeyMultiControlRequestPairing
      method

      KeyMultiControlRequestPairing

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      参数: MultiControlChannel

      启动双控对频操作，可选择把遥控器切换成A控或者B控跟飞行器对频。

      KeyMultiControlAuthorityObtain
      method

      KeyMultiControlAuthorityObtain

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      参数: List<MultiControlAuthorityType>


      抢夺飞行或者云台控制权。当遥控器仅仅拥有云台控制权时，可通过摇杆来控制云台，当用户同时拥有飞行控制权和云台控制权时，摇杆用来控制飞行，波轮用来控制云台。

      KeyMultiControlLockAuthority
      method

      KeyMultiControlLockAuthority

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      参数: MultiControlLockAuthorityInfo


      锁定飞行或者云台控制权, 锁定后控制权将不能被其他控抢夺。

      KeyMultiControlFlightControlAuthorityLockStatus
      method

      KeyMultiControlFlightControlAuthorityLockStatus

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      参数: Boolean

      返回飞行控制权是否锁定。

      KeyMultiControlLostControlNotice
      method

      KeyMultiControlLostControlNotice

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      参数: MultiControlLostControlInfo

      监听具有飞行或者云台控制权的遥控器失去连接的通知事件。当具有飞行控制权的遥控器失去连接的时候，无飞行控制权的遥控器可以调用KeyMultiControlAuthorityObtain接管飞行控制权，也可以调用KeyMultiControlExecuteFailSafeActionWhenLostControl让飞行器立即执行失控行为KeyFailsafeAction。

      KeyMultiControlExecuteFailSafeActionWhenLostControl
      method

      KeyMultiControlExecuteFailSafeActionWhenLostControl

      Since MSDK 5.0.0
      包：dji.sdk.keyvalue.key

      执行失控行为。当具有飞行控制权的遥控器失去连接的时候，无飞行控制权的遥控器可以调用此接口让飞行器立即执行失控行为KeyFailsafeAction。
