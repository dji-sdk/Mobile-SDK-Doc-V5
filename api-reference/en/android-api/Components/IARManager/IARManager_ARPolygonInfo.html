      AR polygon face information entity.

      Package dji.open.pilot.base.manager.arAndroid · Java / Kotlin
      Description:

      AR polygon face information entity. Supports cylinder extrusion. Each endpoint supports embedded AR points.

      Supported since MSDK 5.20.1
