      EllipsizeType

      Package:dji.open.pilot.base.ui.model

      Text truncation type enumeration. When the text exceeds maxLines, it controls how the excess part is displayed.

      Enum Members

      NameDescription
      UNKNOWNUnknown (no truncation is set; the text is cropped directly when it overflows).
      STARTTruncate at the beginning of the text, replaced by an ellipsis (…text).
      MIDDLETruncate in the middle of the text, replaced by an ellipsis (te…xt).
      ENDTruncate at the end of the text, replaced by an ellipsis (text…).
      MARQUEEMarquee effect; the text scrolls for display.
